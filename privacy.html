Политика конфиденциальности Calendar Agent

Дата вступления в силу: 11 октября 2026 г.

Какие данные используются

Calendar Agent получает доступ к Google Календарю владельца аккаунта через Google OAuth только для того, чтобы по его команде просматривать свободное время, создавать, изменять и удалять события и отправлять приглашения участникам.

Как данные хранятся

Данные календаря не продаются, не передаются третьим лицам и не используются для рекламы. Токен доступа хранится на сервере владельца и используется только для работы ассистента.

Соответствие требованиям Google

Использование и передача информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Privacy Policy (English)

Calendar Agent is a personal Telegram assistant that accesses the owner's Google Calendar via OAuth solely to view availability and create, update or delete events and send invitations at the owner's request. Calendar data is not sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: ksenofontov593@gmail.com.
